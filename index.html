見方と注意点

  • 1.00倍付近：どちらの設定でも同程度に起こる。設定が「当たっている」意味ではない。
  • 倍率が大きい：指定した2設定のうち片方を支持する。ただし実設定の確率ではない。
  • 合算の内訳：設定差が小さければ、回数が多くても判別材料として弱いことがある。
  • 設定配分・ブドウ・朝の根拠：この比較には含まれない。続行・撤退や期待時給を自動判定するものではない。
計算の仕組み（少し詳しく）

1Gごとの結果を「BB・RB・その他」の3区分とする多項モデル。各設定のBB・RB確率を使い、観測されたG・BB・RBの尤度比 L(B)/L(A) を計算する。確率の独立抽選と固定設定を仮定した近似モデルだよ。

合算成分は「総ボーナス回数 K」の二項尤度比。構成成分は「ボーナスK回のうちRBがR回」の条件付き二項尤度比。両成分の積が、総合尤度比に正確に一致する。

「差の大きさ」の表示は便宜的な目安で、統計的な信頼度・正解率・設定判定基準ではない。0Gの場合や比較設定が同じ場合は判別しない。

iPhoneのホーム画面に置きたい

GitHub PagesなどのHTTPSサイトとして公開した後、iPhoneのSafariで開き「共有」→「ホーム画面に追加」。初回読み込み後はオフラインでも使える構成。HTMLファイルを直接開くだけでも計算できるけど、ホーム画面アプリ化はHTTPS公開がおすすめ。

本ツールは設定予測を保証しない。確率は公表・解析値の丸めを使用。過去の負けやハマリは次回の当選確率を変えない。実戦判断は投資上限や時間も含めて別途行ってね。
